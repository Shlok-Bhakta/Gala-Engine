## 0.1.0 preview

The first public preview includes Mac builds from Linux, project build and test recipes, private signed delivery, the web installer, and the native Gala companion app source. `gala deliver` requires passing tests and publishes one current IPA per project. The native app's first on-device installation and direct handoff still need hands-on confirmation; the web installer remains the setup path.

The release's generic Gala IPA is **unsigned**. It needs a matching signing certificate and provisioning profile before any device can install it. Owner-signed builds stay on the private tailnet installer.

Read the [0.1.0 preview notes](https://github.com/Shlok-Bhakta/Gala-Engine/blob/main/docs/releases/v0.1.0.md) and the [GitHub releases](https://github.com/Shlok-Bhakta/Gala-Engine/releases) for artifacts and newer releases.
