## Gala Engine 0.1.0 preview

Gala Engine builds iPhone and iPad apps from a Linux checkout using a Mac for the iPhoneOS SDK and signing. The first native Gala companion app is included in this prerelease.

### What works

- `gala test`, `gala build`, `gala run`, and `gala deliver` return logs and artifacts to Linux. `gala deliver` gates on tests, signs on the Mac, and publishes one current build to the private Tailscale installer.
- Project-specific `ios-build.sh` and `ios-test.sh` recipes support SwiftUI, UIKit, C++ ports, React Native, Expo, and other toolchains.
- The native SwiftUI app lists current builds and starts an iOS install handoff. Its progress bar tracks IPA transfer from the Mac, while the existing web installer remains available as a fallback.
- The GitHub README now includes an illustrated app preview and system flow.

### Preview limits

The native app has compiled and passed a Mac-side Swift typecheck. Its first device installation and direct handoff still need hands-on confirmation. Native push notifications are not in this build; the Home Screen web app remains the build-alert path. iOS does not give this app a final installation percentage or support silent app installation on a personal device.

The attached `Gala-0.1.0-unsigned.ipa` is a generic **unsigned** iPhone/iPad build with no tailnet server address embedded. It cannot be installed until signed with your own matching certificate and provisioning profile. See [the native app guide](https://github.com/Shlok-Bhakta/Gala-Engine/blob/main/app/Gala/README.md) for setup. The owner's signed device build is distributed only through the private Tailscale installer.
